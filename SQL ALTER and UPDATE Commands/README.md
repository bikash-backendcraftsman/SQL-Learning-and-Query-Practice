# SQL ALTER and UPDATE Commands

Practice **DDL** (`ALTER`) and **DML** (`UPDATE`) on the **FLIGHT_MANAGEMENT** table.

See also: [Oracle SQL – Command categories](../revision/Oracle-SQL-Command-Categories.md) (DDL vs DML).

## `ALTER TABLE` — understand the difference

| Clause | What it does |
|--------|----------------|
| **ADD** | Creates a **new** column |
| **MODIFY** | Changes the **definition** of an **existing** column (for example data type or size) |

**Examples in this folder:**

- Question 1 — `ADD PILOT_NAME`
- Question 2 — `ADD SEAT_CAPACITY`
- Question 3 — `MODIFY AIRLINE_NAME`
