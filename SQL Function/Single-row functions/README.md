# Single-row functions

Oracle **single-row functions** return one result **per input row**.

## Categories

| Folder | Purpose |
|--------|---------|
| [Character functions](Character%20functions) | `UPPER`, `LOWER`, `SUBSTR`, `LENGTH`, `TRIM`, … |
| [Numeric functions](Numeric%20functions) | `ROUND`, `TRUNC`, `MOD`, `ABS`, … |
| [Date functions](Date%20functions) | `SYSDATE`, `ADD_MONTHS`, `MONTHS_BETWEEN`, … |
| [Conversion functions](Conversion%20functions) | `TO_CHAR`, `TO_NUMBER`, `TO_DATE`, … |
| [NULL functions](NULL%20functions) | `NVL`, `NVL2`, `NULLIF`, `COALESCE`, … |
| [General functions](General%20functions) | `GREATEST`, `LEAST`, `DECODE`, `CASE`, … |
