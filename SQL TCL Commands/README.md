# SQL TCL Commands

Practice **Transaction Control Language** on Oracle: `COMMIT`, `ROLLBACK`, `SAVEPOINT`, and `ROLLBACK TO SAVEPOINT`.

Revision: [Oracle SQL – TCL](../revision/Oracle-SQL-TCL-Transaction-Control.md)

Run these in SQL Developer / SQL\*Plus in order within one session where noted. Review changes with `SELECT` before `COMMIT` or `ROLLBACK`.
